# SVG Icon Creator

A self-contained, single-file browser tool for hand-drawing SVG icons -
rectangles, ellipses, curves, freehand strokes, boolean cut/merge,
non-destructive knockout shapes, rotation/skew, and export (raw, size-
optimized, or standalone-color) as `currentColor`-based SVGs meant for
theming inside an app.

No build step, no dependencies - `index.html` is the entire app.

## Running it

Open `index.html` directly in a browser, or serve this repo via
GitHub Pages.

Project data autosaves to this browser's own `localStorage`. Use
**Save .json** (Project panel) to back up or move a project between
devices/browsers, and **Load .json** to bring one back in.
